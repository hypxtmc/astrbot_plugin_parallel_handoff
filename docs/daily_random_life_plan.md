# 三期·子代理随机化日常 规划书

> 2026-09-03 15:0x，顾主拍板三期重版 + GLM-4-Flash 走 astrbot provider。

## 目标（顾主 09:41 定性 + 14:5x 决策）
接话人**不能被算死**、不能固定套路；每人开启的话题也不固定，应有自己**随机演化的一天日常生活**——天天过着不一样的生活。
引入 LLM 情感仲裁，但**只在数据源层**：GLM-4-Flash 离线闲时读对话，给每人 `random_state` 注入「今日心情/手头事/话题域」的语义温度。裁决仍归规则（快/稳/零实时成本）。

## 核心原则
1. **不推翻读空气四段**：R1/R2/R4 宁静权判据是主判据，绝不删改；三期是**叠加的一个「今日状态契合度」维度**。
2. **LLM 只当眼睛，不当手**：GLM-4-Flash 仅离线注入状态，绝不实时拦截路由、绝不砍 calls、绝不拖接话延迟。
3. **绝对不依赖 LLM**：注入器异常 → 自动降级为纯规则随机状态，不掉链子。
4. **边界守死**：旧怨只作贫嘴/刀子嘴豆腐心，不做对抗性裁决；不做心跳/主动唤醒；不做跨会话全局在场（仍在一期边界内）。

## 数据流
```
（历史对话）
   │  GLM-4-Flash 离线闲时注入（daily_life.inject_states）
   ▼
random_state（每人今日：心情/手头事/话题域）
   │  接话时叠加（后续 steps 接入接话权重）
   ▼
读空气 R1/R2/R4（主判据，不删）+ 今日状态契合度（三期维度）
   ▼
接话人判定（主代理显式 calls 仍绝不砍）
```

## 里程碑（分步独立可验证）
- **M1 状态机 random_state.py**：每人持久化 DailyState（心情/手头事/话题域）+ 每日随机重掷 + 场景隔离。纯规则，不含 LLM。
- **M2 注入器 daily_life.py**：GLM-4-Flash 离线注入器（provider_manager 指定 provider id，llm_generate 调用），异常降级随机。独立可测。
- **M3 接话权重叠加**：random_state 数据接入接话判断，形成「今日状态契合度」| **待顾主验收四类场景后开**。
- **M4 回归+部署**：全量测试 + 热重载 + 顾主四类场景验收（点名/群聊杂谈/承接句/多人并行）。
